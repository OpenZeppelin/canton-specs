# Exemplars

This directory contains executable deliverables that show how the OpenZeppelin
CIP-0112 registry of
[`OpenZeppelin/canton-contracts`](https://github.com/OpenZeppelin/canton-contracts)
integrates with Canton standards and ecosystem tooling. Each exemplar runs in
CI and on a live ledger.

| Area | Contents |
|---|---|
| [Interoperability](interoperability/) | CIP-0086 and CIP-0103 Daml scenarios, the CIP-0104 settlement-attribution walkthrough, the Canton Wallet Gateway harness, the LocalNet traffic-rewards harness, and run evidence |

The exemplars consume the registry as pinned DARs recorded in
[`dars/manifest.yaml`](../dars/manifest.yaml).
