Milestone window
May – July 2026

One consolidation, applied throughout

The token foundation consolidates on CIP-0112

The proposal targeted CIP-56. The ecosystem has since approved the Token Standard V2 upgrade (CIP-0112) superseding it: a consolidation with updates on the ecosystem.

Delivered as proposed

CIP-56 implementation

Delivered by the public canton-token-template (CIP-056 token standard template) and canton-stablecoin

Added beyond the proposal

A Token Standard V2-aligned settlement engine with compliance and seizure extension points. All four Reference Implementations inherit it as their shared base.
