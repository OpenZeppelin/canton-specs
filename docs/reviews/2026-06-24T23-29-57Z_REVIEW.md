# REVIEW

Re-review of RI #1 (Privacy-Preserving DEX, `docs/ri-reports/01-dex.md`) against
a second expert draft: a US-financial-regulation-framed "Architectural Blueprint
for Confidential Canton Reference Implementations" (Token Standard V2 / CIP-0112,
US regulatory alignment). The blueprint spans three RIs — DEX (§7), Lending (§8),
Cross-Chain Stablecoin (§9) — plus a large regulatory/base-layer essay (§1–6,
§10). Per the per-RI review loop, **this pass processes RI #1 (DEX) only**;
Lending and Stablecoin are separate follow-up passes.

Reference-design document; not an M1/M2 acceptance, conformance, audit, or
production-readiness judgment.

## VERDICT

PASS — **integrate-minimal**. The DEX report was already a freshly-reviewed,
grant-aligned v2 ([`2026-06-24T21-54-54Z_REVIEW.md`](./2026-06-24T21-54-54Z_REVIEW.md)).

  production framing) — the report's no-claims banners stand; not relaxed.

## IMPROVEMENTS (integrated into `01-dex.md`)

1. **§7.1 — "Non-custodial venue (no unilateral execution)" security invariant.**
   Promotes the blueprint's strongest real point to a first-class invariant:
   trader is sole signatory able to lock their holding; operator can only
   `SettleBatch` over the exact committed `Allocation` + the trader's own
   min-output `AllocationRequest`, cannot deviate/fabricate/freeze; Daml
   non-transitive authorization; enforced by `extraTransferLegSides` pinning +
   `attestorPool` co-signature. No external/legal citation.
2. **§3 (D4 Authority) — `[FUTURE]` maker-checker note.** Institutional
   internal authorization (maker proposes, checker approves) via the
   propose-accept two-step handshake + distinct `oz-access-control` role grants,
   leaving the external `PoolRules` interface unchanged; explicit SCU extension
   point, not M1 scope, not a separate settlement/authority path.
3. **§3 (SCU Extension Story) — `[UPSTREAM]` retroactive-interface-instance
   removal.** Records that Daml 3.x removed retroactive interface instances and
   that the RI therefore uses forward-compatible interface hierarchies + new
   templates/choices, reinforcing the existing SCU narrative.
