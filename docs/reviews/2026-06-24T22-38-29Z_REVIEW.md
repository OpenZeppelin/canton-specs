# REVIEW

## VERDICT

PASS after fixes. The expert draft of RI #2 (Institutional Lending Protocol) is
structurally complete and well-aligned with the decided D1–D4 semantics and the
grant's fixed-rate/credential-gated scope, but — like the DEX draft — shipped
with fabricated API identifiers, hallucinated external citations, footnote
noise, and no source-grounding discipline. All blocking issues are corrected in
the persisted report [`docs/ri-reports/02-lending.md`](../ri-reports/02-lending.md),
which also carries the Cross-Synchronizer Domain Extension section (§8), the
house conventions, and the grant-alignment banner.

This review is for a reference-design document. It is not an M1/M3 acceptance,
conformance, audit-readiness, or production-readiness judgment.

## BUGS

Fabricated / inaccurate identifiers (verified against real source 2026-06-24):

- **`VaultFactory_CreateVault`** — no such choice. Real entry point is
  **`VaultFactory_OpenVault`**. *Fixed:* RI adapter delegates to it.
- **Vault `Borrow` / `Repay` choices** — not the real names. Real choices are
  **`Vault_MintStablecoin`** (borrow) and **`Vault_BurnStablecoin`** (repay);
  also **`Vault_DepositCollateral`**, **`Vault_WithdrawCollateral`**,
  **`Vault_Close`**. *Fixed:* §3 flow and code use the real names.
- **`VaultParams.collateralizationRatio`** — real fields are
  **`minCollateralRatio`** and **`liquidationRatio`** (plus `liquidationBonus`,
  `stabilityFeeRate`). *Fixed.*
- **`PriceOracle.priceInDebtDenomination` / `provider` signatory** — real shape
  is `{admin, collateralInstrumentId, price, updatedAt, observers}`, signatory
  `admin`, choice `PriceOracle_UpdatePrice`. *Fixed.*
- **`D2SeizureHook` as a template with a `D2SeizureHook_Sweep` choice** — wrong.
  `D2SeizureHook` is a spine **data record** (`seizureCaseRef`,
  `custodianDestination`, `inFlightHandlingStatus`). Seizure runs via
  `Allocation_MarkD2InFlightSeizure` → `Allocation_SweepD2InFlightSeizure` (or
  `LockedSimpleHolding_ForcedBurn` for locked collateral), gated by
  `BurnerCapability`. *Fixed:* §3 D2 + §4.4 rewritten to the real mechanism.
- **`MockVerificationResult.isValid`** — not a real field; real fields include
  `outcome` / `result`. *Fixed:* uses an `isAccepted` predicate, illustrative.
- **`KycClaim` / `TrustedIssuerRegistry` attributed to `zk-credential-gateway`** —
  these are the typed D3 **Shape-B** types in the `canton-specs` identity-hook
  experiments. *Fixed:* attribution corrected with an explicit note.
- **`SettleBatch with instructions = [...]`** — aligned to the real shape used
  across the spine (`allocations = [...]`, `requests = [...]`). *Fixed.*

Confirmed-correct (kept): `OpenZeppelin.Experimental.Settlement.Cip112`,
`SettlementFactory_SettleBatch`, `Allocation`, `BurnerCapability`,
`Vault_Liquidate`, `SimpleHolding`/`LockedSimpleHolding`/`*_ForcedBurn`,
`SimpleTokenRules`, `TransferPreapproval`, `CredentialGatedActionRequest`,
`MockVerificationResult`, `CredentialRevocationStatus`, `nextIterationFunding`.
