## GAPS

Portfolio-level gaps (all additive; now closed):

- **No suite-level synthesis.** With four reports done one-at-a-time, nothing
  expressed the cumulative view. *Added* `00-portfolio.md`: the suite at a
  glance, the shared foundation (described once), the composition map, cumulative
  scope (union in/out), the shared cross-synchronizer model, the
  library-extraction map (per-RI → M2/M3/M4), and the cross-RI consistency
  guarantees.
- **Missing inter-RI composability links (4).** The reports under-stated how the
  RIs interlock. *Added* a "Composability with the other RIs" bullet to each
  report's §9: DEX ⇽ Stablecoin (pool reserves from cross-chain inflows) + DEX as
  Auction's secondary market; Lending → Auction (liquidation fair-value recovery)
  + Lending ⇽ Auction (collateralized bidding); Stablecoin → DEX/Lending
  (post-settlement liquidity/collateral); Auction → DEX + Auction ⇽ Lending. All
  realized over the same `SettleBatch` spine — no parallel paths.
- **Cross-synchronizer mechanism duplicated four times with no owner.** The §8
  mechanism is identical across reports. *Added* the canonical shared model to
  `00-portfolio.md` §5 and a "Shared model" pointer at the top of each report's
  §8; each §8 now elaborates only RI-specific topology.
