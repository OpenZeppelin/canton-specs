# REVIEW

## VERDICT

PASS after fixes. The expert draft of RI #1 (Privacy-Preserving DEX) is
structurally complete and well-aligned with the decided D1–D4 semantics, but
shipped with fabricated API identifiers, garbled inline math, and external
hallucinated citations that would fail the ground-truth and citation-hygiene
gates. All blocking issues are corrected in the persisted report
[`docs/ri-reports/01-dex.md`](../ri-reports/01-dex.md). The report now also
carries the required Cross-Synchronizer Domain Extension section (§8) and the
house conventions (Google Docs import note, source-grounding tags, no
readiness claims).

This review is for a reference-design document. It is not an M1 acceptance,
conformance, audit-readiness, or production-readiness judgment.

## BUGS

Fabricated identifiers that do not exist in workspace source (verified against
`canton-specs`/`canton-contracts`/`canton-token-template`/`canton-stablecoin`/
`zk-credential-gateway` on 2026-06-24):

- **`OpenZeppelin.Experimental.Settlement.Cip112.Interfaces`** — no such module.
  All spine code is in the single `OpenZeppelin.Experimental.Settlement.Cip112`
  module. *Fixed:* imports corrected.
- **`AllocationFactory` template / `AllocationFactory_Allocate` choice** — do not
  exist. The real allocation-creation path is
  `SettlementFactory_CreateAllocationInstruction` → `AllocationInstruction_Accept`
  → `Allocation`; requests use `SettlementFactory_CreateAllocationRequest`.
  *Fixed:* flow steps, snippets, and the sequence diagram now use the real path.
- **`D2SeizureHook` as a template with an `ExecuteSeizure` choice** — wrong.
  `D2SeizureHook` is a **data record** (`seizureCaseRef`, `custodianDestination`,
  `inFlightHandlingStatus`); seizure runs via the real `Allocation` choices
  `Allocation_MarkD2InFlightSeizure` then `Allocation_SweepD2InFlightSeizure`
  (gated by `BurnerCapability`). *Fixed:* §4.3 rewritten to the real shapes.
- **`D1ComplianceHook` typed as `ContractId D1ComplianceHook`** — it is a config
  **data record** (`hookRef`, `requiresPerSettlementReference`). *Fixed:* `Pool`
  now carries `Optional D1ComplianceHook`.
- **`KycClaim` / `TrustedIssuerRegistry` attributed to `zk-credential-gateway`** —
  these are the typed D3 **Shape-B** types in the `canton-specs`
  identity-hook-shape-b / identity-hook-upgrade experiments. *Fixed:* attribution
  corrected with an explicit note.

Confirmed-correct identifiers (kept): `SettlementFactory_SettleBatch`,
`nextIterationFunding`, `extraTransferLegSides`, `BurnerCapability`,
`SimpleHolding`/`LockedSimpleHolding`/`*_ForcedBurn`, `SimpleTokenRules`,
`TransferPreapproval`, `Vault`/`VaultFactory`/`VaultParams`/`PriceOracle`,
`CredentialGatedActionRequest`/`MockVerificationResult`.

## GAPS

- **Citation integrity (blocking).** The draft's "Works cited" listed external,
  non-workspace, hallucinated sources as authoritative: a
  `srikanth-bitdynamics/Canton-Dex-Reference-Implementation` GitHub repo (not in
  this workspace), Medium ecosystem round-ups, and a CoinStats "fundamental
  analysis" page. *Fixed:* replaced with a workspace-grounded References section
  citing exact file paths; the removal is disclosed in-report.
- **Missing cross-synchronizer planning.** Required by the operator for all RIs.
  *Fixed:* added §8 (Cross-Synchronizer Domain Extension, `[FUTURE]`), grounded
  in Canton's real per-synchronizer assignment + reassignment (unassign/assign)
  model and the SCU additive rule, with extension path and open questions.
- **No source-grounding discipline.** The draft made no distinction between
  implemented, evidence, upstream, and proposed code. *Fixed:* applied the
  `[IMPLEMENTED]/[EVIDENCE]/[UPSTREAM]/[FUTURE]` tag convention from
  `cip0112-m1-ri-spec.md`; RI-level `Pool`/`PoolRules` are tagged `[FUTURE]`.

## ANTI-PATTERNS

- **Garbled inline math.** LaTeX placeholders collapsed to empty `()` throughout
  ("single liquidity pool ()", "verifying that ,", "AMM Conservation ()").
  *Fixed:* restored `x · y = k` and the explicit fee-adjusted conservation
  inequality.
- **Footnote-marker noise.** Superscript citation digits were inlined as stray
  trailing numerals ("CLOBs1", "balance sheets2", "scenarios8"). *Fixed:*
  removed; replaced with the grounded References section.
- **Fabricated precision.** The draft asserted specific validation-ladder
  latencies ("< 1 second", "~30 seconds", "~2 seconds") as if benchmarked.
  *Fixed:* labeled illustrative, not benchmarked.
- **Readiness over-claim.** Phrasing leaned toward "certify production-readiness"
  and "zero business-logic refactoring." *Softened* to "assess readiness" and
  "intended to make this a thin substitution," with an explicit no-claims status
  banner (AGENTS.md scope rules).
